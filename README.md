## 💻 Memulai di Lingkungan Lokal (*Quick Start*)

Jika Anda ingin mengunduh dan menjalankan proyek ini di mesin lokal, ikuti langkah-langkah berikut:

**1. Clone Repositori**

```bash
git clone https://github.com/iqbaleff214/STIK4111-PEMROGRAMAN-BERBASIS-WEB.git

```

**2. Pindah ke Direktori Tugas**

```bash
cd STIK4111-Pemrograman-Web/tugas1

```

**3. Jalankan Aplikasi**
Karena proyek ini berjalan murni di sisi klien (*Client-side*), Anda tidak perlu menginstal *dependencies* eksternal seperti `npm`.

* Cukup buka file `index.html` secara langsung di *browser* (Chrome/Firefox/Edge).
* **Atau** gunakan ekstensi **Live Server** di Visual Studio Code untuk pengalaman pengembangan dengan fitur *Hot Reload*.
